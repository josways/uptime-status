# 升级计划：react-scripts (CRA) → Vite

## 项目概述

- **类型**：简单的前端静态页面
- **功能**：UptimeRobot API 多实例状态展示
- **构建工具**：react-scripts 5.0.1 (已弃用)
- **目标**：迁移到 Vite

## 当前技术栈

| 依赖 | 版本 | 处理 |
|------|------|------|
| react | 18.2.0 | 保留 |
| react-dom | 18.2.0 | 保留 |
| react-scripts | 5.0.1 | **移除** |
| axios | 0.27.2 | 保留 |
| dayjs | 1.11.3 | 保留 |
| sass | 1.53.0 | 升级 |
| react-tooltip | 4.2.21 | 保留 |

## 迁移步骤

### Phase 1：基础配置变更

#### 1.1 更新 package.json

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "axios": "^0.27.2",
    "dayjs": "^1.11.3",
    "react-tooltip": "^4.2.21",
    "sass": "^1.63.0"
  },
  "devDependencies": {
    "@vitejs/plugin-react": "^4.2.0",
    "vite": "^5.0.0"
  }
}
```

**变更说明**：
- `react-scripts` → `vite` + `@vitejs/plugin-react`
- `sass` 升级到最新版本以兼容 Vite
- scripts 从 `start/build` 改为 `dev/build/preview`

#### 1.2 创建 vite.config.js

```js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    open: true
  },
  build: {
    outDir: 'build',
    sourcemap: false
  }
});
```

**说明**：
- `outDir` 保持为 `build` 以兼容现有部署
- `port 3000` 与原 CRA 默认一致

### Phase 2：入口文件调整

#### 2.1 移动 index.html 到 src 目录

CRA 从 `public/index.html` 读取，Vite 从 `src/index.html` 读取。

```
public/index.html → src/index.html
```

#### 2.2 更新 index.html 中的路径引用

```html
<!-- 修改前 (CRA) -->
<script src="./config.js"></script>

<!-- 修改后 (Vite) -->
<script src="/config.js"></script>
```

**说明**：Vite 中 public 目录的文件通过绝对路径 `/` 访问

### Phase 3：环境变量适配

#### 3.1 更新 .env 文件（如果存在）

CRA 使用 `REACT_APP_` 前缀，Vite 使用 `VITE_` 前缀。

```env
# .env
REACT_APP_API_KEY=xxx → VITE_API_KEY=xxx
```

#### 3.2 代码中的环境变量

如果代码中有 `process.env.REACT_APP_*`，需改为 `import.meta.env.VITE_*`

### Phase 4：验证与测试

#### 4.1 安装依赖

```bash
npm install
```

#### 4.2 测试开发模式

```bash
npm run dev
```

#### 4.3 测试构建

```bash
npm run build
```

#### 4.4 验证构建产物

确认 `build/` 目录输出正确

## 风险点与注意事项

| 项目 | 说明 |
|------|------|
| 路径别名 | 项目未使用路径别名，无影响 |
| CSS Modules | 项目使用单一 SCSS 文件，无影响 |
| Proxy 配置 | 如有 `proxy` 配置需迁移到 `vite.config.js` 的 `server.proxy` |
| PWA | 项目未使用，无影响 |
| 代码分割 | 项目无此需求，无影响 |

## 兼容性说明

### 需要确认的功能

1. **config.js 运行时配置**
   - 当前：`window.Config` 在 `public/config.js` 中定义
   - Vite：`public/` 目录文件直接复制到输出，可通过 `/config.js` 访问
   - **状态**：✅ 兼容

2. **SCSS 样式**
   - Vite 原生支持 SCSS，无需额外配置
   - **状态**：✅ 兼容

3. **react-tooltip**
   - Vite 完全支持
   - **状态**：✅ 兼容

## 回滚方案

如迁移失败，还原方式：
1. 恢复 package.json
2. 恢复 index.html 到 public/
3. 删除 vite.config.js
4. 重新安装 node_modules
